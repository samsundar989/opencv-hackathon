# Platform check — Oct 22, 2026 (OpenCV AI Competition 2026)

All pages fetched Oct 22, 2026. [U] means unverified or inconsistent.

## 1. OpenCV 5.1: not released. Stay on 5.0.0.93
- GitHub releases: the latest tag is **5.0.0** (Jun 6), followed by 4.14.0 (Jul 19). There is no 5.1 tag. https://github.com/opencv/opencv/releases
- The **5.1 milestone** is open, 57% done (211/366 issues), with no due date. 4.15.0 is 41% done. https://github.com/opencv/opencv/milestones
- PyPI opencv-python-headless: the newest upload is **4.14.0.94 (Jul 28, 2026)**, and the newest 5.x is **5.0.0.93 (Jul 2, 2026)**. PyPI still labels 5.0.0.93 as "Latest". There is no 5.1 wheel. https://pypi.org/project/opencv-python-headless/#history
- The 5.0.0.93 wheels are **cp37-abi3** (stable ABI), including manylinux_2_28_aarch64 and manylinux2014_aarch64. **There is no cp314-specific wheel, and none is needed.** abi3 installs on CPython 3.14, and the classifiers list 3.14. https://pypi.org/project/opencv-python-headless/5.0.0.93/#files
- DNN engine enums are the same in the 5.0 and 5.x docs: `ENGINE_AUTO` (default, 3), `ENGINE_NEW` (2), `ENGINE_CLASSIC` (1), `ENGINE_ORT` (4), plus the `OPENCV_FORCE_DNN_ENGINE` env var. The docs mention no rename. https://docs.opencv.org/5.x/main_modules/dnn_engine_selection.html
- ALIKED/LightGlue, imwriteanimation, FaceDetectorYN: **[U]** No 5.1 notes exist yet, and GitHub PR search is blocked by robots, so I could not check for API changes.
- **Recommendation: stay pinned to 5.0.0.93.** No 5.1 wheel exists, and 4.14.0.94 is a 4.x line, so it is not an upgrade path.

## Implications
1. Stay on 5.0.0.93. The aarch64 abi3 wheel works on Py3.14 Graviton.
2. For "Best Use of COOL" on Python 3.14, the **G5 AMI on m9g** is the only COOL option with a 3.14 venv, and it is cheap. Because it claims OpenCV 5.1.0, record `cv2.__version__` and the build info as evidence. The G4 AMI and the Docker image would force Python 3.12.
3. Use the `us.` cross-region inference profile for Bedrock calls from us-east-2.
